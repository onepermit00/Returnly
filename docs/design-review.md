# Back — On reference review

Reviewed the metadata and preview images of all 100 On desktop screens returned by the Refero connector for site 809. Four contact sheets covered all previews. Three key screens were inspected at full resolution. This is an adaptation for Back, using original campaign imagery and return-tracking content.

## Design decisions

- Landing: full-width campaign photo, lower-left headline, three editorial cards, split benefits section, rule-separated FAQ, large closing statement. Primary references: homepage 56cd3077-3ae6-412d-9d37-ae453b35e3be and membership 3b42cf8a-b6f6-4700-a486-980254af111e.
- Desktop: global header, horizontal account navigation, white canvas, thin rules, bold type and rectangular product tiles. Primary references: account dashboard 5f4cd8a9-a2fc-495b-aa6e-eeea45fc0243 and favorites 37929465-c102-430d-b4c5-57838489f37c.
- Purchase details: four-stage progress timeline, clear facts and packing checklist, adapted from order details 73053eef-af5e-4039-9ed4-96a30b0622d8.
- Product filters: purchases use catalog filtering, with urgency, unconfirmed policies and progress. Reference a06e8eb2-e262-4ada-9391-5be3b33d5c34.
- Added functional areas: monthly deadline calendar; separate cash/credit received totals and pending returns; persisted packing checklist; CSV preview/import/export.
- Excluded shopping checkout, payment, loyalty/referral and retail store finder patterns because Back tracks existing purchases.
